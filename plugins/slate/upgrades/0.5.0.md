# Upgrading to Slate 0.5.0

## What's new

- **OpenCode V2 is a third host.** The same skills, board and one-time unlock work in OpenCode 2.x
  alongside Claude Code and GitHub Copilot CLI. No npm package is needed: the plugin lives in the
  project, and OpenCode-only users can install it from a release with
  `scripts/assemble_opencode.py` (no Claude Code or Copilot install required).
- **The guard holds in OpenCode too.** A direct edit to `kanban/tickets.json` is denied with the
  actionable `fix:` message. An unlock command from the agent is refused, because a card reply
  cannot be told apart from `--auto`'s automatic reply: run `board.py unlock` in your own terminal
  and type the code it shows. That still allows exactly one edit.
- Nothing changes in Claude Code or Copilot CLI. Board schema stays at 3.

## Steps

These run after the board files are replaced (only the version number changes in them).

### 1. Refresh the OpenCode plugin folder

- **Check:** the project has `.opencode/plugins/slate/index.js` and seven
  `.opencode/commands/slate-*.md` stubs, all at version 0.5.0.
- **Do:** assemble `.opencode/plugins/slate/` from the installed `plugins/slate` folder (skills,
  guard, board assets, templates, reference, upgrades, CHANGELOG and `plugin.json`) plus
  `plugins/slate/opencode/` (the JS plugin, `package.json` and command stubs), then refresh
  `.opencode/commands/slate-*.md`. The exact bash and PowerShell commands are in
  `/slate:upgrade` step 2b. This is a straight replacement — no user answers are stored there.

### 2. Add SLATE.md to OpenCode's project config

- **Check:** `opencode.jsonc` (or `opencode.json`) exists and `instructions` contains `"SLATE.md"`.
- **Do:** if the file is missing, create it with `"$schema": "https://opencode.ai/config.json"`
  and `"instructions": ["SLATE.md"]`. If it exists, merge that one value and keep every other key.
  Do not add a `plugins` entry: OpenCode loads `.opencode/plugins/` automatically.

### 3. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).

### 4. Restart OpenCode

- **Do:** quit and relaunch OpenCode (or restart its background service with
  `opencode service restart`) before using the refreshed plugin. A stale service hides plugin
  changes, so the new skills and guard may not load until you do.
