# Upgrading to Slate 0.2.1

## What's new

- **Clone and go:** Slate adds itself to the project's `.claude/settings.json` (the file in the
  repo — never your personal `~/.claude/settings.json`). Anyone who clones the repo and accepts
  Claude Code's folder-trust prompt gets Slate loaded and kept up to date (`"autoUpdate": true`),
  with no install command.
- When the project's board is newer than your plugin (a teammate upgraded first), Slate offers to
  run the plugin update for you.
- `doctor` checks the team settings: `team-settings-missing` is a problem to fix;
  `team-settings-ignored` (the file is in `.gitignore`) is only a note.

## Steps

### 1. Team settings

- **Check:** `python3 kanban/board.py doctor --json` lists `team-settings-missing`.
- **Do:** merge into the project's `.claude/settings.json` (create it if missing; keep every other
  key):

  ```json
  {
    "extraKnownMarketplaces": {
      "slate": { "source": { "source": "github", "repo": "Zidane786/slate" }, "autoUpdate": true }
    },
    "enabledPlugins": { "slate@slate": true }
  }
  ```

  Tell the user what was added and to commit it. If doctor's notes include
  `team-settings-ignored`, don't touch `.gitignore`; say that people who clone the repo won't get
  Slate automatically until `.claude/settings.json` is committed.

### 2. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).
