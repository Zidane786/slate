# Upgrading to Slate 0.3.0

## What's new

- **Cancelled:** a built-in state for work you've decided not to do. Cancel with
  `python3 kanban/board.py cancel <ID> --reason "why"` (or from the board page). It never counts as
  done, and tickets that depend on it are no longer blocked (each gets a note). Undo with
  `python3 kanban/board.py uncancel <ID> --handoff "why"`.
- **Progress shows it separately:** "3/15 done · 1 cancelled".
- **State behaviours for any state:** e.g. a "Won't fix" state that works like Cancelled:
  `python3 kanban/board.py add-status wontfix --after done --like cancelled --label "Won't fix"`,
  or tune one behaviour: `python3 kanban/board.py edit-status on_hold folded=true`.

## Steps

### 1. Board schema 3

- **Check:** `python3 kanban/board.py version` shows schema 2 (or doctor lists `schema-outdated`).
- **Do:** `python3 kanban/board.py migrate` (also run by `board.py upgrade`). It adds the
  Cancelled state after Done; a state already named "cancelled" becomes the built-in one. Nothing
  is removed. Tell the user what changed.

### 2. Regenerate the `## Workflow` section of `SLATE.md`

- **Check:** `python3 kanban/board.py doctor --json` lists `slate-md-workflow-stale`.
- **Do:** ask the user, then replace the whole `## Workflow` section with the output of
  `python3 kanban/board.py workflow --markdown`.

### 2b. New `SLATE.md` section

- **Check:** `doctor --against "<ROOT>"` lists `slate-md-sections` (0.3.0 adds
  `## Cancelling and finished states`).
- **Do:** add the missing section from the plugin's `templates/SLATE.md`, keeping everything the
  project wrote.

### 3. Offer a custom finished state (optional)

- **Check:** the team has tickets it closes without doing them for different reasons (won't fix,
  duplicate).
- **Do:** ask whether they want extra states like "Won't fix" or "Duplicate" that behave like
  Cancelled; show the resulting columns as a picture; only on a yes run
  `python3 kanban/board.py add-status <name> --after done --like cancelled --label "<Label>"`.

### 4. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).
