# Upgrading to Slate 0.2.2

## What's new

- **Per-state dependency rule:** for each state, which states a ticket's dependencies must be in
  before a ticket can move there. By default, **Waiting for merge** accepts dependencies in
  Waiting for merge or Done, so tickets in the same PR no longer block each other; Done still
  needs them Done. Change it with `python3 kanban/board.py edit-status <state> deps=a,b`
  (`deps=none` turns the check off, `deps=` goes back to the default).
- **The live board page acts as you:** a ticket you took from the page ("Take") can be moved and
  released by you; your name goes with every change from the page.

## Steps

### 1. Regenerate the `## Workflow` section of `SLATE.md`

- **Check:** `python3 kanban/board.py doctor --json` lists `slate-md-workflow-stale` (0.2.2 adds a
  "Dependencies must be in" column to the section).
- **Do:** ask the user, then replace the whole `## Workflow` section of `SLATE.md` with the output
  of `python3 kanban/board.py workflow --markdown` (add nothing inside it).

### 2. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).
