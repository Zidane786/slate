# Upgrading to Slate 0.4.0

## What's new

- **GitHub Copilot CLI:** the same Slate plugin now works in Copilot CLI, with the same commands
  (`/slate:plan`, `/slate:work`, …) and the same board. Install it there with
  `copilot plugin marketplace add Zidane786/slate` and `copilot plugin install slate@slate`.
- **The guard holds in Copilot, even in Autopilot with Allow all:** direct edits to
  `kanban/tickets.json` are blocked there too. An unlock still needs your Yes on Copilot's
  approval card.
- Nothing changes in Claude Code.

## Steps

These run after the board files are replaced (only the version number changes in them).

### 1. Update the unlock line in `SLATE.md`

- **Check:** `SLATE.md` contains `Copilot CLI support: planned.`
- **Do:** ask the user ("Slate now works in GitHub Copilot CLI too. Update the unlock note in
  SLATE.md to say so? (Y/n)"). On yes, replace `Copilot CLI support: planned.` with
  `In GitHub Copilot CLI the card shows in every mode, even Autopilot with Allow all (a
  copilot -p run refuses it).` Change nothing else.

### 2. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).
