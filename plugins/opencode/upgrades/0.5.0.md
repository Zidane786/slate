# Upgrading to Slate 0.5.0

## What's new

- **OpenCode V2 is a third host.** The same skills, board and one-time unlock work in OpenCode 2.x
  alongside Claude Code and GitHub Copilot CLI. No npm package or global install is needed: the
  plugin lives in the project.
- **The guard holds in OpenCode too.** A direct edit to `kanban/tickets.json` is denied with the
  actionable `fix:` message; `board.py unlock` shows OpenCode's permission card, and one approval
  allows exactly one edit. In a non-interactive run, use the terminal-code fallback in another pane.
- Nothing changes in Claude Code or Copilot CLI. Board schema stays at 3.

## Steps

These run after the board files are replaced (only the version number changes in them).

### 1. Refresh the OpenCode plugin folder

- **Check:** the project has `.opencode/plugins/slate/index.js` and seven
  `.opencode/commands/slate-*.md` stubs, all at version 0.5.0.
- **Do:** copy the whole installed plugin folder over `.opencode/plugins/slate/` and the command
  stubs over `.opencode/commands/` (the exact commands are in `/slate:upgrade` step 2b). This is
  a straight replacement — no user answers are stored there.

### 2. Add SLATE.md to OpenCode's project config

- **Check:** `opencode.jsonc` (or `opencode.json`) exists and `instructions` contains `"SLATE.md"`.
- **Do:** if the file is missing, create it with `"$schema": "https://opencode.ai/config.json"`
  and `"instructions": ["SLATE.md"]`. If it exists, merge that one value and keep every other key.
  Do not add a `plugins` entry: OpenCode loads `.opencode/plugins/` automatically.

### 3. Run `doctor` until healthy

- **Check / do:** `python3 kanban/board.py doctor --against "<ROOT>"`; fix each problem it lists
  (asking first).
