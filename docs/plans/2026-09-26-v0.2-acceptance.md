**Deliberate differences**

- **#6:** comma lists split labels, areas and dependencies — *not* acceptance or test sentences,
  which contain commas ("When x, then y"); repeat the flag for those.
- **#21:** instead of a record the hook simply honours, approval is the user's own action (Claude
  Code's permission card, or a typed code in a terminal); an agent alone can only create a request.
